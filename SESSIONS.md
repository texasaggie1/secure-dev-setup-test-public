# SESSIONS.md: Sample

The running log of every work session, so any AI or person can pick up cold. **Newest entry at the top.**

- Read the top 3 entries before you start. Add a new entry at the top before you stop.
- Never rewrite an old entry. If one turns out to be wrong, say so in a new entry.
- This file goes to GitHub. No secrets. No client personal data. Point to a file in `private-data/` instead.
- When this file passes 500 lines, move all but the newest 10 entries to `docs/sessions-archive.md`, in a commit of its own.
- A planned or proposed item is not a finished item. Do not treat "Next" as done.

Use this format for every entry:

```
## Session N: YYYY-MM-DD (short title)
**Tool:** which AI tool and which person
**Asked for:** one or two lines
**Done:** what changed and where
**Verified:** what you actually ran or looked at, and what happened
**Not verified:** what you did not check
**Decisions:** choices the owner made, with name and date. Copy lasting ones to CLAUDE.md
**State:** what is on testing but not yet on main, any production changes, any database changes
**Next:** the first thing the next session should do
```
